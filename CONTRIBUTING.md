# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. **Fork** this repository.
2. **Clone** your fork to your computer:
   ```
   git clone https://github.com/YOUR-USERNAME/simple-interest-calculator.git
   ```
3. **Create a branch** for your change:
   ```
   git checkout -b my-change
   ```
4. **Make your changes**, then commit them with a clear message:
   ```
   git add .
   git commit -m "Describe your change"
   ```
5. **Push** the branch to your fork:
   ```
   git push origin my-change
   ```
6. **Open a pull request** on GitHub describing what you changed and why.

## Reporting bugs

Open an issue and include what you expected to happen, what actually happened, and the steps to reproduce the problem.

## Suggesting ideas

Open an issue describing your idea and how it would improve the project.

## Code of Conduct

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) when taking part in this project.
